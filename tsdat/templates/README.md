# Bundled pipeline project template

This directory contains a snapshot of the tracked files in
[tsdat/pipeline-template](https://github.com/tsdat/pipeline-template), revision
`646d1aa` (September 2026), adapted for `tsdat init` and `tsdat create-pipeline`.
The original template's `LICENSE.md` accompanies the snapshot.

When updating this snapshot, copy only tracked files from the upstream repository,
exclude its Git metadata, caches, and issue/PR templates, then reapply the changes
to `templates/generate.py`, the project README and requirements-dev.txt. Check
wheel and sdist contents, and run the generated project's tests and example ingest.
